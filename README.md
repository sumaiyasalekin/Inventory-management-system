## ✨ Features & Modules

### Inventory & Catalog Management
* **RESTful API Architecture:** Custom backend endpoints (`/products`, `/transactions`) to perform CRUD database operations and maintain transaction records.
* **Interactive Product Catalog:** Front-end web interface for searching, updating, and managing product items.

### Staff & Transaction Monitoring
* **Dashboard Analytics:** Visual overview tracking transaction logs, stock metrics, and staff records.
* **Purchase Processing:** Forms and backend handlers for executing transactions and logging sales histories.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
* **Backend:** Node.js, Express.js
* **Database:** MongoDB (`db.js`)

## 🎨 Design & System Components

| Category | Included Components |
| :--- | :--- |
| **Data Display** | Analytics Dashboards, Transaction Logs, Product Catalogs |
| **API Endpoints** | REST Routes (`/products`, `/transactions`), Database Layer (`db.js`) |
| **Core Workflows** | Staff Operations, Inventory Tracking, Purchase Processing |
